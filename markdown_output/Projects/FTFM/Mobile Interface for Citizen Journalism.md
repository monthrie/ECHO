## Project Overview
This project aims to develop a mobile application that allows journalists and citizens to contribute real-time voice reports. These reports will be automatically transcribed and structured into the FTFM database.

### Key Features
- **Real-Time Transcription**: Convert voice reports into text.
- **Entity Extraction**: Identify key topics and events.
- **Instant Database Integration**: Store submissions in the FTFM platform.

### Project Timeline
- **Priority**: High
- **Deadline**: June 1, 2025
- **Status**: Planning
