## Project Overview
The FTFM project aims to create an AI-powered system that transforms journalism from its traditional report-based model into a structured, searchable database. The core functionalities include extracting and storing entities (people, places, events, policies), tracking public claims, and identifying contradictions in public statements.

### Key Features
- **Entity Extraction**: Automatically identify and categorize key entities from news sources.
- **Claim Tracking**: Monitor public statements over time.
- **Statement Half-Life**: Analyze how long statements remain unchallenged before being contradicted.
- **Narrative Collision Detection**: Detect conflicting narratives across different sources.
- **Credibility Scoring**: Assign scores to sources based on their history of accuracy.
- **AI & Graph Databases**: Use advanced AI models and databases for efficient information retrieval.

### Timeline & Priority
- **Priority**: High
