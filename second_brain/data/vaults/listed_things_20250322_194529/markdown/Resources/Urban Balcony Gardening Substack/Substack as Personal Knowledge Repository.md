# Substack as Personal Knowledge Repository

The Urban Balcony Gardening Substack will function as both a creative outlet and knowledge repository, documenting gardening experiences and serving as a reference source even if it doesn't attract a large audience. This dual purpose ensures the project has value regardless of commercial success.
