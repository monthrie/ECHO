# Follow The Money Project Overview

## Project Description

The 'Follow The Money' (FTFM) project aims to create a system that tracks and analyzes statements from news sources and podcasts. The core concept is building a fact-tracking database that serves as a source of truth, allowing easy verification of statements made by public figures and tracking how their positions evolve over time.

## Purpose

This system would function as society's 'storage layer' for tracking real-world events and statements - something currently missing from our information ecosystem. Unlike Wikipedia, which focuses on static, historical information, this system would track dynamic, evolving narratives and statements made by public figures.

## Key Objectives

1. Create a structured database of public statements and claims
2. Track the evolution of positions over time
3. Identify contradictions, hypocrisies, and conflicts of interest
4. Provide a searchable record of promises and their fulfillment status
5. Offer a reliable source of truth for fact-checking

## Differentiators

Unlike existing fact-checking services or news aggregators, FTFM would:

- Focus on structured data rather than narrative articles
- Track statements over time to identify patterns and changes
- Create a comprehensive, searchable database of claims
- Provide direct links to original sources with timestamps
- Offer both human-readable and machine-readable formats

## Project Timeline

- Initial concept development: Q4 2023
- MVP development: Q1 2024
- Technical architecture: Q2 2024
- Core system implementation: Q2-Q3 2024
- Advanced features: Q3-Q4 2024
- Full system launch: End of 2024
