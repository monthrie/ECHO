# Follow The Money Project - Contents

## Project Overview
The Follow The Money (FTFM) project aims to create a structured database of news and public statements to hold public figures accountable. This system will extract entities and claims from media, track promises, identify pattern changes in statements, and create a searchable 'source of truth' system.
