# FTFM Position Change Tracker

## Overview
The Position Change Tracker will detect when public figures change their positions or contradict previous statements. This system creates transparency around inconsistencies and enables citizens to easily verify how someone's stated positions have evolved over time.

## Key Features

### Position Statement Identification
- Extract clear position statements on specific topics
- Categorize statements by subject matter and stance
- Link statements to their full context for accurate interpretation

### Contradiction Detection
- Compare new statements against historical positions
- Identify logical inconsistencies between statements
- Distinguish between evolution of thought and direct contradictions

### Consistency Scoring
- Develop metrics for measuring position consistency over time
- Generate consistency scores for individuals on specific topics
- Provide transparency about methodology behind consistency assessments

### Timeline Visualization
- Create visual representations of position changes
- Enable users to explore the evolution of positions chronologically
- Provide direct access to source material for each position statement

## Technical Challenges
- Will require sophisticated natural language understanding to detect subtle shifts in position versus outright contradictions
- Need to account for legitimate context changes that might justify position shifts
- Must balance algorithmic assessment with human judgment

## Implementation Approach
- Begin with clear-cut position statements on well-defined topics
- Gradually increase sophistication to handle nuanced position changes
- Incorporate user feedback to improve detection accuracy
