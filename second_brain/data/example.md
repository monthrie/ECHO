# Sample Obsidian File

This is a simple demonstration file showing Obsidian's linking capabilities.

## Quick Reference
| Link Type | Syntax | Example |
| --------- | ------ | ------- |
| File link | `[[filename]]` | [[File_1]] |
| Section link | `[[filename#section]]` | [[#section_3]] |
| Alias link | `[[filename\|alias]]` | [[File_1\|See related content]] |

## section_1
Some content here.

## section_2
More information.

## section_3
This is the section we're linking to from above.

### Sub-section
- You can also combine different link types
- For example: [[File_1#some_section\|Named link to specific section]]
